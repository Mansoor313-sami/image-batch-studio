    Google Flow helper

    1. Download the helper extension and unzip it.
    2. Open chrome://extensions (or edge://extensions), turn on Developer mode, and choose Load unpacked.
    3. Open Google Flow in another tab, sign in, and open a project.
    4. Reload this page. The status above turns green.

    API keys

    Google's free tier often allows no image requests, so the Gemini engine usually needs billing on this key.

    Without a key, Pollinations makes one smaller image about every 45 seconds. A free key unlocks more models, full size and parallel images.
